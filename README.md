# Exploration Camp

A simple web-based game where players explore the solar system.

## Features

*   Purchase different rockets (Scout, Hauler, Explorer).
*   Buy fuel and repair rockets on Earth.
*   Travel between planets (Mercury, Venus, Earth, Mars, Jupiter, Saturn, Uranus, Neptune).
*   View an animated star map with orbiting planets and names.
*   Gather resources via a mini-game on different planets.
*   Sell gathered resources at the market.
*   Take quizzes about planets to earn credits.
*   View interesting facts about each planet.
*   Restart game functionality.
*   Instructions modal.
*   Mobile detection notice (recommends desktop).

## How to Play

1.  Start on Earth.
2.  Buy a rocket.
3.  Buy fuel.
4.  Launch exploration to view the star map.
5.  Click a planet to travel (requires fuel).
6.  On planets, gather resources, take quizzes, or sell resources.
7.  Visit all planets (excluding Earth) to win.

## Deployment

This game is built with HTML, CSS, and JavaScript and can be hosted on any static web hosting service, including GitHub Pages.
